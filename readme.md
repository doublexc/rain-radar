# 🌧️ ฝนมาหรือยัง? (Is Rain Coming?)

เว็บแอปประเมินว่าฝนกำลังเข้าใกล้ตำแหน่งของคุณหรือไม่ จากภาพเรดาร์ตรวจจับฝนแบบแอนิเมชัน (GIF) ของกรมอุตุนิยมวิทยา / กทม. เป็น **Static Web** ล้วน ๆ (HTML/CSS/JavaScript ไฟล์เดียวต่อหน้า) ใช้งานบน GitHub Pages ได้เลยโดยไม่ต้องมี Backend

## 📂 โครงสร้างโปรเจกต์

โปรเจกต์มี 2 หน้า ใช้งานแยกกัน:

| ไฟล์ | หน้าที่ | เหมาะกับ |
|---|---|---|
| `index.html` | **เรดาร์เตือนฝนหนองแขม** — ปักหมุดตำแหน่งคุณบนภาพเรดาร์ (ด้วย GPS, การแตะ หรือกรอกพิกัด) แล้วแสดงวงรัศมี 5 / 10 / 20 กม. รอบตัว เพื่อดูว่าก้อนฝนอยู่ใกล้แค่ไหน | ดูภาพรวมเร็ว ๆ ว่าฝนอยู่ใกล้ตัวหรือยัง |
| `manual.html` | **ฝนมาหรือยัง?** — วิซาร์ด 6 ขั้นตอน ติดตามก้อนฝนจากเฟรมเก่าไปเฟรมปัจจุบัน แล้วคำนวณ % โอกาสที่ฝนจะมาถึงและเวลาที่คาด | อยากได้ตัวเลขโอกาสและเวลาโดยประมาณ |

## ✨ จุดเด่น

* 📱 **Mobile-First:** ออกแบบสำหรับใช้บนมือถือเป็นหลัก
* 📡 **ดึงภาพเรดาร์สดอัตโนมัติ:** ภาพ GIF ย้อนหลังประมาณ 50 นาที (11 เฟรม ห่างกันเฟรมละ 5 นาที)
* 🛡️ **Network Resiliency:** ถ้าดึงภาพตรงไม่ได้จะสลับไปใช้ Proxy สำรองอัตโนมัติ
* 🎨 **Canvas Overlay:** ซ้อน `<canvas>` โปร่งใสทับภาพ GIF จึงวาดหมุด วงรัศมี และเวกเตอร์ทับภาพเคลื่อนไหวได้ลื่น

### เฉพาะ `index.html`
* 📍 **ปักหมุดได้ 3 วิธี:** กดปุ่ม GPS, แตะบนภาพ หรือกรอกพิกัดเอง
* ⌨️ **กรอกพิกัดเองได้ 2 โหมด:** สลับระหว่าง **ละติจูด / ลองจิจูด** (ค่าเริ่มต้น) กับ **Pixel (X, Y)** ค่าที่กรอกค้างไว้จะถูกแปลงตามให้เมื่อสลับโหมด
* 🎯 **วงรัศมีเตือน:** 5 กม. (แดง), 10 กม. (ส้ม), 20 กม. (เหลือง)
* 🔒 **แจ้งเตือนเมื่ออยู่นอกพื้นที่:** ถ้าตำแหน่งอยู่เกิน 120 กม. จากสถานี จะแจ้งว่านอกขอบเขตตรวจวัด

### เฉพาะ `manual.html`
* 🔁 **Auto-Fallback แหล่งภาพ:** สลับสถานีหนองแขม ↔ หนองจอก ↔ กทม. อัตโนมัติเมื่อแหล่งใดแหล่งหนึ่งใช้ไม่ได้
* 📁 **อัปโหลด GIF จากเครื่อง:** ใช้เป็นทางสำรองเมื่อเซิร์ฟเวอร์ภายนอกล่ม
* 🧮 **Vector Math:** คำนวณความเร็วฝน (px/นาที) และเทียบทิศทางกับตำแหน่งผู้ใช้ด้วย Dot Product ร่วมกับ Heuristic Scoring

## 🛠️ วิธีใช้งาน

### `index.html`

1. เปิดหน้าเว็บ รอภาพเรดาร์โหลด
2. ปักหมุดตำแหน่งของคุณ ด้วยวิธีใดวิธีหนึ่ง:
   * กดปุ่ม **ดึงตำแหน่งจาก GPS**
   * แตะบนภาพเรดาร์
   * กรอก **ละติจูด / ลองจิจูด** (หรือสลับเป็น Pixel) ในช่อง "ระบุตำแหน่งหมุดเอง" แล้วกด **ย้าย** (หรือกด Enter)
3. ดูว่าก้อนฝนในภาพ (สีเขียว → เหลือง → แดง ตามความแรง) เข้ามาอยู่ในวงรัศมี 20 / 10 / 5 กม. หรือยัง
4. กดรีเฟรชเพื่อโหลดภาพล่าสุดใหม่ (ภาพอัปเดตตามรอบของกรมอุตุฯ)

### `manual.html`

1. **โหลดภาพเรดาร์:** ดึง GIF ล่าสุด (11 เฟรม ย้อนหลังประมาณ 50 นาที)
2. **จุดผู้ใช้ (📍):** แตะบนภาพเพื่อปักตำแหน่งของคุณ
3. **ทิศฝน (↗️):** ลากลูกศรบนภาพเพื่อระบุทิศที่ก้อนฝนเคลื่อนไป
4. **ตำแหน่งฝน (A → B):** แตะก้อนฝนก้อนเดิมในเฟรมเก่า (จุด A) และเฟรมปัจจุบัน (จุด B)
5. **ความแรง:** เลือกสีหลักของกลุ่มฝน (เขียว = เบา, เหลือง = ปานกลาง, แดง = หนัก)
6. **ผลลัพธ์:** แสดง **% โอกาสที่ฝนจะตกถึงคุณ** และ **เวลาคาดการณ์ (นาที)**

**วิธีคิดคะแนนโดยสังเขป:** เริ่มที่ 30% แล้วบวก/ลบตามทิศทางที่ชี้เข้าหาคุณ ระยะห่าง เวลาที่คาดว่าจะมาถึง และความแรงของฝน จำกัดผลลัพธ์ไว้ระหว่าง 5–95% (ระยะห่างคิดเป็นพิกเซลบนภาพ ไม่ได้แปลงเป็นกิโลเมตร)

## 📐 การปรับเทียบพิกัด (Calibration) — `index.html`

หน้า `index.html` แปลงละติจูด/ลองจิจูดเป็นพิกเซลบนภาพเรดาร์ ด้วยการประมาณแบบเส้นตรงจากจุดศูนย์กลาง (สถานีหนองแขม) ค่าคงที่อยู่ต้นส่วน `<script>`:

```js
const RADAR_STATION   = { lat: 13.7056, lon: 100.3547 }; // ที่ตั้งสถานีหนองแขม
const RADAR_CENTER_PX = { x: 483, y: 414 };              // พิกเซลของสถานีบนภาพ 960×800
const KM_PER_PX       = 0.30;                            // 120 กม. = 400 px
```

**ที่มาของค่า:** หาจากจุดอ้างอิงจริง 3 จุด (ปากแม่น้ำท่าจีน, ปากแม่น้ำแม่กลอง และตำแหน่งของผู้พัฒนาเอง) แล้วตรวจซ้ำกับอีก 3 จุด (เกาะสีชัง, พระนครศรีอยุธยา, หาดชะอำ ที่ระยะ 110 กม.)

**ความแม่นยำ:** ที่ระยะ 38–96 กม. จากสถานี คลาดเคลื่อนราว 1–3 พิกเซล (ประมาณ 1 กม.) และที่ขอบวง (ชะอำ ~110 กม.) ตกตรงชายฝั่งเมื่อกรอกพิกเซลเอง ซึ่งแม่นพอสำหรับการประเมินฝนด้วยสายตา

> ตัวเลขข้างต้นยืนยันโดยเทียบกับ Google Maps ด้วยมือ ใช้พิกัดจุดอ้างอิงที่ได้มาโดยประมาณ จึงมีความคลาดเคลื่อนระดับ ±1–2 กม. เป็นธรรมดา

### ถ้าหมุดกลับมาเพี้ยน

กรมอุตุฯ อาจเปลี่ยนขนาดหรือกรอบภาพ หรือถ้าเพิ่มสถานีสำรองเข้าใน `index.html` ก็ต้องปรับค่าแยกตามภาพของแต่ละสถานี วิธีปรับ:

1. เลือกจุดอ้างอิงที่เห็นชัดบนภาพ (ปากแม่น้ำ เกาะ ชายฝั่ง) อย่างน้อย 2–3 จุด ให้กระจายคนละทิศ และไกลกันพอสมควร
2. หาละติจูด/ลองจิจูดของแต่ละจุดจาก Google Maps
3. แตะจุดเดียวกันบนภาพเรดาร์ จดค่า Pixel (X, Y) ที่แอปแสดง
4. คำนวณหา `KM_PER_PX` (จากระยะจริงเทียบกับระยะพิกเซลระหว่างจุด) และ `RADAR_CENTER_PX` ให้ค่าที่ได้ทำนายตำแหน่งทุกจุดได้ใกล้เคียงที่สุด
5. แก้ค่าคงที่ข้างต้น แล้วตรวจซ้ำด้วยจุดใหม่ที่ไม่ได้ใช้ปรับ โดยเฉพาะจุดใกล้ขอบวง

## 🚀 การติดตั้งและ Deploy

โปรเจกต์เป็น Vanilla HTML/CSS/JavaScript ไม่ต้อง Build

1. **Clone Repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/rain-radar.git
   cd rain-radar
   ```

2. **เปิดใช้งานบน Local:**
   เปิด `index.html` หรือ `manual.html` ผ่านเว็บเบราว์เซอร์ได้ทันที

   > การอนุญาตตำแหน่ง GPS ของเบราว์เซอร์ต้องใช้ HTTPS (หรือ `localhost`) ถ้าเปิดไฟล์ตรง ๆ แล้วปุ่ม GPS ใช้ไม่ได้ ให้ลองรันเซิร์ฟเวอร์ชั่วคราว เช่น `python3 -m http.server`

3. **Deploy ขึ้น GitHub Pages:**
   * ไปที่ **Settings** > **Pages** ของ Repository
   * เลือก Source เป็นสาขา `main` และโฟลเดอร์ `/ (root)`
   * กด **Save** แล้วรอสักครู่ จะได้ URL ประมาณ `https://YOUR_USERNAME.github.io/rain-radar/` (หน้า `manual.html` อยู่ที่ `.../manual.html`)

4. **หลังอัปเดตไฟล์:** ถ้าเปิดแล้วยังเห็นของเดิม ให้รีเฟรชแบบล้างแคช (Ctrl+F5)
